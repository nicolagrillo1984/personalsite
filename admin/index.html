Accesso privato — modifica diretta dei file del blog su GitHub, nessun database.

Come funziona: questa pagina usa un tuo token GitHub personale per leggere e scrivere i file del blog direttamente nel repository. Il token resta solo nel browser (non viene mai inviato altrove) e scompare quando chiudi la scheda.
Come creo il token?
1. Vai su GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
2. In "Repository access" seleziona solo questo repository.
3. In "Permissions" → "Contents" imposta Read and write. Lascia tutto il resto senza accesso.
4. Imposta una scadenza breve (es. 30-90 giorni) e rigeneralo quando serve.

Non condividere mai questo token. Non viene salvato: va reinserito a ogni nuova sessione.
